처음 설정하기: 키 발급과 깃허브 페이지에 올리는 방법

1. 깃허브 페이지에 앱 올리기 (무료)

  1. github.com에 가입하고 로그인해요.
  2. 오른쪽 위 + → New repository. 이름은 travel-guide, Public으로 두고 Create repository.
  3. 새 저장소 화면의 uploading an existing file을 눌러 받은 index.html을 끌어다 놓고 Commit changes.
  4. Settings → Pages에서 Source를 Deploy from a branch, Branch를 main / (root)로 고르고 Save.
  5. 1~2분 뒤 https://내아이디.github.io/travel-guide/로 접속돼요. 이 주소를 아래 키 설정에 등록해요.
  6. 휴대폰에서 이 주소를 열고 브라우저 메뉴의 홈 화면에 추가를 누르면 앱처럼 쓸 수 있어요.

2. 카카오맵 키 (국내 여행)

  1. 카카오디벨로퍼스에 카카오 계정으로 로그인 → 내 애플리케이션 → 애플리케이션 추가하기.
  2. 앱의 앱 키 화면에서 JavaScript 키와 REST API 키를 복사해요.
  3. 플랫폼(Web) 또는 JavaScript 키 설정에서 JavaScript SDK 도메인에 https://내아이디.github.io를 등록해요.
  4. 앱 관리 페이지의 [카카오맵] → [사용 설정]을 ON으로 바꿔요. 처음 만든 앱 하나에만 무료 사용량이 있어요.
  5. 아래 칸에 두 키를 붙여넣고 저장하고 연결을 누른 뒤 페이지를 새로고침해요.

3. 구글 지도 키 (해외 여행, 선택)

  1. Google Cloud 콘솔에서 새 프로젝트를 만들고 결제 계정을 연결해요. 무료 사용량 안에서 써도 결제 계정은 필요해요.
  2. API 및 서비스 → 라이브러리에서 Maps JavaScript API, Places API (New), Routes API를 사용 설정해요.
  3. 사용자 인증 정보 → API 키 만들기. 애플리케이션 제한은 웹사이트로 하고 https://내아이디.github.io/*를 넣어요. API 제한은 위 세 가지로.

4. Claude API 키 (AI 기능, 선택)

  1. Claude Console에서 API 키를 만들고 크레딧을 충전해요. 쓴 만큼 요금이 나가요.
  2. 키가 없어도 지도, 길찾기, 경비 기능은 모두 쓸 수 있어요. AI 추천·도우미만 꺼져요.

키는 이 기기 브라우저에만 저장돼요. 깃허브에 올리는 index.html에는 키가 들어가지 않으니 저장소가 공개여도 괜찮아요. 다만 이 기기를 다른 사람과 같이 쓰면 키가 보일 수 있으니 주의하세요.
